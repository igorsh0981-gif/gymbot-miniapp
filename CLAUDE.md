# GymBot Mini App — правила проекта

## «Что нового» — обязательно для каждой новой функции
- Каждая новая функция для пользователей приложения получает слайд в «Что нового»
  (`whatsNewSlides` в `src/App.jsx`): `since` = версия выкладки (дата, при нескольких
  выкладках за день — с буквой: `2026-10-25b`), и `WN_VERSION` = эта же версия.
- Кто видел прошлую подборку, при входе увидит только новые слайды; новичок и
  «Сервисы» → «Что нового» — все.
- Правки и исправления ошибок слайдов не получают.
- Тексты — на 4 языках (ru, en, uz, kz); у слайда кнопка, которая сразу открывает функцию.
- e2e: сценарии 58–64 проверяют подборку — при новом слайде обновить число слайдов и версию.

## Проверка перед выкладкой
- `npx vite build && node e2e/run.mjs` — все сценарии должны пройти.
